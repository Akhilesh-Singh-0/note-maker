# 📝 Note Maker App

A simple **Note Maker web app** built using **HTML, CSS, and Vanilla JavaScript**.

This project focuses on **core frontend fundamentals** like state management, DOM manipulation, CRUD operations, and data persistence using `localStorage`.

---

## 🚀 Features

- Create notes (title + content)
- Edit existing notes
- Delete notes
- Persistent data using `localStorage`
- State-driven UI rendering

---

## 🛠️ Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage
